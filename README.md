# Student Grade Management System

## Description
A simple Java console-based application for managing student grades.

## Features
- Enter student names and grades
- Calculate average score
- Find highest score
- Find lowest score
- Display a summary report
- Uses ArrayList for storing student data

## Technologies Used
- Java
- ArrayList
- Scanner
- Object-Oriented Programming

## How It Works
The program takes the number of students, their names, and their subject grades as input. It then calculates the average, highest, and lowest scores and displays a summary report for each student.
